showing draft text

This website will never be finished.

  I decided that an extended mode of the website itself is as good a place as any to prototype planned new subjects and text, reminders to self, and any other comments and "todo" items. I decided to add an option to toggle all of these notes to self on and off in one go.

  Showing such draft text is a feature for my personal use. It is not meant for your eyes. But on the other hand, it is no big secret either, so if you are curious what I had in mind in the long run, then feel free to click the button "Show draft text" below. All draft menu items and text will appear on a yellow background.

  Your choice will be persistent over sessions ( technically, it is a CSS variable stored in your browser's "local­Storage" ), so if you want to go back to normal view, click "Hide draft text" below, or delete your browsing history.

     


  If you see this text, draft mode is "on".
